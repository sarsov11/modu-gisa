시험 전날 체크

코드 출력 문제에서 답이 갈리는 곳과 SQL 문법만 모았습니다. 회색 상자의 출력은 실제로 실행한 값입니다. 확인한 줄은 체크해 두면 이 기기에 남습니다.

Java출력 함정

부모 타입 변수로 자식 객체를 가리키면, 메서드는 자식 것 · 필드와 static 메서드는 변수 타입(부모) 것 
A o = new B();      // B extends A, 둘 다 x·f()·static s() 가 있음
o.f()  o.x  o.s()   → Bf 1 As
자식 객체를 만들면 부모 생성자가 먼저 돈다 
new B();   // A() 가 "A", B() 가 "B" 를 찍음 → AB
static 변수는 객체 전부가 하나를 같이 쓴다 
static int cnt; 생성자에서 cnt++ → 객체 3개 만든 뒤 cnt → 3
정수끼리 나누면 몫만 남는다, 문자 + 정수는 정수 
7 / 2 → 3     7 / 2.0 → 3.5     'A' + 1 → 66
문자열 + 는 왼쪽부터: 앞에 문자열이 있으면 이어 붙이고, 숫자끼리 먼저 만나면 더한다 
"" + 1 + 2 → 12      1 + 2 + "" → 3
== 는 같은 객체인지, equals 는 내용이 같은지 
String p = "A", q = new String("A");
p == q → false     p.equals(q) → true

C출력 함정

*(p+1) 은 다음 칸 값, *p+1 은 첫 칸 값에 1을 더한 것 
int a[] = {10, 20, 30}; int *p = a;
*(p+1)  *p+1  p[2] → 20 11 30
구조체 포인터는 p->x 와 (*p).x 가 같다 
struct P s = {3, 4}; struct P *sp = &s;
sp->x  (*sp).y → 3 4
switch 에 break 가 없으면 아래 case 로 계속 내려간다 
k = 2: case 1 "1" / case 2 "2" / case 3 "3"; break → 23
i++ 는 지금 값을 쓰고 나서 1을 더한다 
int i = 5; printf("%d ", i++); printf("%d", i); → 5 6
strlen 은 '\0' 앞까지 글자 수, sizeof 는 배열 크기 
char str[10] = "abc"; strlen(str) sizeof(str) → 3 10
비트 연산은 2진수로 바꿔서 
5 >> 1 → 2  (101 → 10)     5 & 3 → 1  (101 & 011)

Python출력 함정

슬라이싱 [a:b] 는 b 앞에서 끝난다, 음수는 뒤에서부터 
s = "PYTHON"
s[1:4]  s[-2:]  s[::-1] → YTH ON NOHTYP
// 는 몫(음수면 더 작은 쪽으로), ** 는 오른쪽부터 계산 
7 // 2   7 / 2   2 ** 3 ** 2   -7 // 2 → 3 3.5 512 -4
print 는 sep 기본 공백, end 기본 줄바꿈 
print("a", "b", sep="-", end="!\n") → a-b!
b = a 는 복사가 아니라 같은 리스트를 가리킨다 
a = [1, 2]; b = a; b.append(3); print(a) → [1, 2, 3]

SQL문법 한 장

실행 순서FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
WHERE / HAVING행을 거르면 WHERE, 묶은 뒤 집계로 거르면 HAVING
GROUP BY 학과 HAVING AVG(점수) >= 80
COUNTCOUNT(*) 는 NULL 행도 세고 COUNT(열) 은 NULL 을 뺀다 (4행 중 NULL 1개 → 4 / 3)
NULL 비교= NULL 은 늘 0건, IS NULL · IS NOT NULL 로 쓴다
LIKE% 글자 수 상관없음, _ 한 글자 · LIKE '이%'
BETWEEN · INBETWEEN 1 AND 3 은 1과 3 포함 · IN ('A','B')
ORDER BY기본 ASC(오름차순), 내림차순은 DESC · 여러 열이면 앞 열부터
JOINSELECT … FROM A JOIN B ON A.키 = B.키 · 한쪽 행을 다 남기면 LEFT OUTER JOIN
집합UNION 은 중복을 지우고 UNION ALL 은 그대로 · INTERSECT 교집합 · EXCEPT(MINUS) 차집합
DMLINSERT INTO 표(열1, 열2) VALUES (값1, 값2);
UPDATE 표 SET 열 = 값 WHERE 조건;
DELETE FROM 표 WHERE 조건;
DDLCREATE TABLE · ALTER TABLE 표 ADD 열 타입 · DROP TABLE 표 CASCADE(참조하는 것까지) / RESTRICT(참조가 있으면 거부)
CREATE INDEX 이름 ON 표(열); · CREATE VIEW 이름 AS SELECT …;
DCLGRANT SELECT ON 표 TO 사용자 WITH GRANT OPTION;
REVOKE SELECT ON 표 FROM 사용자 CASCADE;
DISTINCTSELECT DISTINCT 학과 FROM 학생 · COUNT(DISTINCT 열)
